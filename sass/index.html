    Since 0.2.4 — <p>initial release</p>
    @function density_dpi($bucket) { ... }
    View source

    Description

    Get DPI for Density Bucket

    Returns the DPI (dots per inch) for a named density bucket.

    Android bucket names (mdpi … xxxhdpi) return Android's DPI values (160dpi baseline, so xhdpi is 320). Any other name is resolved through density() and multiplied by the CSS reference DPI (96), so retina is 192. Use the latter scale for CSS resolution media queries.

    $bucket

    Parameters

    		Number— none
    $increment

    The exponent applied to the golden ratio, default is 1.

    		Number— none

    The calculated size based on the golden ratio.

    Usage Example

    // Increase size using the golden ratio
.element {
