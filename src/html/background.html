About

Background

The story behind unit.gl — why we created a new approach to responsive design and the principles that guide its development.

The Problem

Modern web development has a spacing problem. We've all been there:

  • Arbitrary pixel values scattered throughout stylesheets
  • Inconsistent spacing that "looks right" but has no underlying logic
  • Responsive designs that break at unexpected viewport sizes
  • Z-index wars with values climbing into the thousands
  • Typography that doesn't scale harmoniously with layout

Design systems attempt to solve this with spacing tokens like $spacing-sm, $spacing-md, $spacing-lg. But these are often arbitrary choices — why is "medium" 16px instead of 14px or 18px? Why these breakpoints and not others?

unit.gl takes a different approach. Instead of arbitrary tokens, we use mathematical relationships rooted in typography, music theory, and the physical world.

The Kyū Unit

At the heart of unit.gl is the Kyū (級, きゅう) — a Japanese unit of measurement traditionally used in typography. One Kyū equals exactly 0.25mm, making it one of the smallest practical units in print design.

In the digital realm, we redefine the Kyū as:

1Q = 1/16rem = 0.0625rem ≈ 1px (at 16px base font size)

This isn't arbitrary. The number 16 is fundamental to digital typography:

  • 16px is the default browser font size
  • 16 divides evenly by 2, 4, and 8 (common grid intervals)
  • 16-point grids are industry standard in UI design
  • 16 Q = 1rem creates a simple mental model

The beauty of the Q unit is that it provides pixel-level precision while remaining fully scalable. If a user increases their browser font size, your entire layout scales proportionally — without breaking.

Why "Kyū"?

The word 級 (kyū) means "grade," "level," or "rank" in Japanese. It reflects the hierarchical nature of the unit — each Q is a building block that combines to create larger structures. The term also connects unit.gl to the rich tradition of Japanese typography and its meticulous attention to proportion.

The Q-System

Building on the Kyū unit, we developed a complete sizing system based on consistent multipliers:

Level Q Value Multiplier Size (mm) Size (px)
Q0 1 ×1 0.25mm ~1px
Q1 160 ×160 40mm ~160px
Q2 320 ×2 80mm ~320px
Q3 480 ×3 120mm ~480px
Q4 640 ×4 160mm ~640px
Q5 800 ×5 200mm ~800px
Q6 960 ×6 240mm ~960px

Each Q-level is exactly 160Q (or 40mm) larger than the previous. This creates a perfectly linear scale that's easy to reason about and produces harmonious relationships between sizes.

Q Format Paper System

unit.gl breakpoints are derived from the Q paper format system — a geometric series where each size is 1.5× the previous:

  • Physical foundation — Breakpoints map to real paper dimensions
  • 4× multiplier — 1mm = 4px at 96dpi (standard screen density)
  • Density-aware — Scales correctly across device pixel ratios

Harmony in Design

The relationship between music and visual design has been understood since antiquity. The same ratios that create consonant musical intervals also create pleasing visual proportions.

unit.gl includes these classical ratios as first-class citizens:

Ratio Value Musical Interval Use Case
Minor Second 1.067 Semitone Subtle variations, micro-adjustments
Major Second 1.125 Whole tone Text sizes, tight scales
Minor Third 1.2 — Balanced typography
Major Third 1.25 — Clear hierarchy
Perfect Fourth 1.333 — Strong contrast
Perfect Fifth 1.5 — Classic proportions
Golden Ratio 1.618 — Natural beauty, organic feel

These ratios power the modular_scale() function, allowing you to create type scales, spacing systems, and layouts that feel inherently harmonious.

Swiss Design Influence

unit.gl is deeply influenced by the Swiss International Typographic Style (also known as the International Style), which emerged in the 1950s from the work of designers like Josef Müller-Brockmann, Max Bill, and Armin Hofmann.

Key principles we've adopted:

Grid Systems

Mathematical grids bring order and consistency. Every element has a precise position determined by the underlying structure.

Objective Typography

Type choices based on legibility and function, not decoration. Clear hierarchy through size, weight, and space.

Asymmetric Balance

Dynamic compositions that feel balanced without being symmetrical. Tension creates visual interest.

Reduction

Remove everything that doesn't serve a purpose. Every element must justify its existence.

Design Philosophy

unit.gl is built on several core beliefs:

Constraints Enable Creativity

Working within a system frees you from endless micro-decisions. When spacing, sizing, and proportions follow clear rules, you can focus on the problems that actually matter.

Mathematics Over Magic Numbers

Every value in unit.gl can be traced to a mathematical relationship. No arbitrary choices, no "this looks about right." Predictable, reproducible, explainable.

Accessibility by Default

Using rem-based units means your layouts automatically respect user preferences. If someone needs larger text, your entire design scales with them.

Print and Screen Unity

The Q unit bridges digital and physical media. The same proportional thinking that produces beautiful books produces beautiful interfaces.

Why "unit.gl"?

The name reflects our focus:

  • unit — The fundamental building blocks of design. Everything starts with the Q.
  • .gl — Originally from Greenland's country code TLD, but for us it evokes "global" and "grid layout." It's also satisfyingly short.

We wanted a name that was memorable, typed easily, and communicated what the library is about at a glance.
