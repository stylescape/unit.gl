Customization

Configuration

Customize unit.gl by overriding variables, extending maps, and configuring build options.

Variables

unit.gl uses SCSS variables with the !default flag, allowing you to override them before importing the library.

Override Pattern

// _your-config.scss
        // Override variables BEFORE importing unit.gl

        // Custom base unit
        $unit_base: 0.0625rem; // Default: 0.0625rem (1px)

        // Custom typography scale
        $scale_ratio: 1.25; // Default: 1.618 (golden ratio)

        // Custom breakpoints
        $breakpoint_md: 800px; // Default: 768px

        // Then import unit.gl
        @use "unit.gl" with (
        $unit_base: $unit_base,
        $scale_ratio: $scale_ratio
        );
Tip: Use the @use ... with () syntax for the cleanest configuration pattern.

Unit Configuration

Variable Default Description
$unit_base 0.0625rem Base Q unit (1px at 16px root)
$unit_base_px 1px Base unit in pixels
$root_font_size 16px Assumed browser root font size 
// Using a 4px base unit instead of 1px
        $unit_base: 0.25rem;

        // Now q(4) = 1rem = 16px
        // q(8) = 2rem = 32px

Scale Configuration

Variable Default Description
$scale_base 1rem Base value for modular scale
$scale_ratio 1.618 Default scale ratio (golden ratio)

Configuring Typography Scale

// Use Major Third for tighter scale
        $scale_ratio: 1.25;

        // Or Perfect Fifth for dramatic scale
        $scale_ratio: 1.5;

        // Custom type scale
        $type_scale: (
        "xs": modular_scale(-2),
        "sm": modular_scale(-1),
        "base": modular_scale(0),
        "md": modular_scale(1),
        "lg": modular_scale(2),
        "xl": modular_scale(3),
        "2xl": modular_scale(4),
        "3xl": modular_scale(5),
        );

Q Steps Scale

The $q_steps map defines which Q values generate utility classes.

Default Scale

$q_steps: (
        0, 1, 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48,
        56, 64, 72, 80, 96, 112, 128, 144, 160, 192, 224, 256
        ) !default;

Customizing

// Minimal scale for smaller CSS output
        $q_steps: (0, 4, 8, 16, 24, 32, 48, 64);

        // Extended scale for more precision
        $q_steps: (
        0, 1, 2, 3, 4, 5, 6, 8, 10, 12, 14, 16,
        20, 24, 28, 32, 40, 48, 56, 64, 80, 96, 128
        );

        // 4px-based scale (multiples of 4)
        $q_steps: (0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96);

Breakpoint Configuration

Customize responsive breakpoints by overriding the $breakpoints map. Default values are derived from Q format paper sizes (mm × 4).

Default Breakpoints

$breakpoints: (
        us: 250px, // Q07 Portrait (62.5mm)
        ss: 360px, // Q06 Portrait (90mm)
        xs: 540px, // Q05 Portrait (135mm)
        sm: 720px, // Q04 Portrait (180mm)
        md: 1080px, // Q04 Landscape (270mm)
        lg: 1440px, // Q03 Landscape (360mm)
        xl: 2160px, // Q02 Landscape (540mm)
        sl: 2880px, // Q01 Landscape (720mm)
        ul: 4320px, // Q00 Landscape (1080mm)
        ) !default;

Customizing

// Tailwind-style breakpoints
        $breakpoints: (
        sm: 640px,
        md: 768px,
        lg: 1024px,
        xl: 1280px,
        2xl: 1536px,
        );

        // Bootstrap-style breakpoints
        $breakpoints: (
        sm: 576px,
        md: 768px,
        lg: 992px,
        xl: 1200px,
        xxl: 1400px,
        );

Layer Configuration

Customize z-index layers via $layer_map.

Default Layers

$layer_map: (
        "canvas": -1000,
        "background": 0,
        "content": 2000,
        "interface": 4000,
        "modal": 7000,
        "guides": 9998,
        "debug": 9999,
        ) !default;

Customizing

// Add custom layers
        $layer_map: (
        "canvas": -1000,
        "background": 0,
        "content": 1000,
        "dropdown": 2000,
        "sticky": 3000,
        "overlay": 4000,
        "modal": 5000,
        "toast": 6000,
        "tooltip": 7000,
        "guides": 9998,
        );

        // Usage
        .dropdown { z-index: z("dropdown"); }
        .toast { z-index: z("toast"); }

Ratio Configuration

Extend or customize aspect ratios via $ratio_map.

Default Ratios

$ratio_map: (
        "square": (1, 1),
        "photo": (4, 3),
        "landscape": (3, 2),
        "wide": (16, 9),
        "ultrawide": (21, 9),
        "golden": (1.618, 1),
        "a_series": (1, 1.4142),
        "portrait": (2, 3),
        ) !default;

Customizing

// Add custom ratios
        $ratio_map: map.merge($ratio_map, (
        "cinema": (2.35, 1),
        "imax": (1.43, 1),
        "instagram": (1, 1),
        "instagram-story": (9, 16),
        "twitter": (16, 9),
        "linkedin": (1.91, 1),
        ));

        // Usage
        .cinema-frame {
        @include aspect_ratio--"cinema");
        }

Build Configuration

Control what gets generated in your CSS output.

// Disable utility classes generation
        $generate_utilities: false;

        // Disable responsive utilities (smaller output)
        $generate_responsive_utilities: false;

        // Choose which utility types to generate
        $generate_spacing_utilities: true;
        $generate_size_utilities: true;
        $generate_gap_utilities: true;
        $generate_ratio_utilities: false; // Skip ratio utilities

        // Import after configuration
        @use "unit.gl";

Complete Configuration Example

A full example of a customized unit.gl setup.

// _config.scss
        // Complete unit.gl configuration

        @use "sass:map";

        // ===================================
        // Unit System
        // ===================================

        $unit_base: 0.0625rem; // 1px base
        $root_font_size: 16px;

        // ===================================
        // Scale System
        // ===================================

        $scale_ratio: 1.25; // Major Third
        $scale_base: 1rem;

        $q_steps: (
        0, 4, 8, 12, 16, 24, 32, 48, 64, 96, 128
        );

        // ===================================
        // Breakpoints
        // ===================================

        $device_map: (
        "sm": 640px,
        "md": 768px,
        "lg": 1024px,
        "xl": 1280px,
        );

        // ===================================
        // Layers
        // ===================================

        $layer_map: (
        "base": 0,
        "dropdown": 100,
        "sticky": 200,
        "modal": 300,
        "toast": 400,
        );

        // ===================================
        // Colors
        // ===================================

        $color_map: (
        "brand": (
        "base": #6366f1,
        "light": #818cf8,
        "dark": #4f46e5,
        ),
        "neutral": (
        "base": #6b7280,
        "light": #9ca3af,
        "dark": #4b5563,
        ),
        );

        // ===================================
        // Build Options
        // ===================================

        $generate_utilities: true;
        $generate_responsive_utilities: true;

        // ===================================
        // Import unit.gl with configuration
        // ===================================

        @forward "unit.gl" with (
        $unit_base: $unit_base,
        $scale_ratio: $scale_ratio,
        $q_steps: $q_steps,
        $device_map: $device_map,
        $layer_map: $layer_map,
        $color_map: $color_map,
        );
