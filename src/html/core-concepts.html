Core Concepts

The foundational principles behind unit.gl: the Kyū measurement system, modular scales, and design harmony.

The Kyū (Q) Unit

At the heart of unit.gl is the Kyū (級, Japanese for "grade" or "level"), a micro-unit that provides pixel-level precision while remaining scalable and accessible.

1Q = 0.0625rem = 1/16rem ≈ 1px (at 16px base font size)

The Q unit bridges the gap between pixel-perfect design and responsive, accessible layouts:

Context 1Q Equals Use Case
Digital (16px base) 1px Screen layouts, web interfaces
Digital (scaled) Scales with rem Accessible, user-preference aware
Print 0.25mm Physical media, typography

Why REM-based?

Using rem ensures your layouts respect user font size preferences, making your designs accessible by default.

The q() Function

The q() function is your primary tool for applying Q units:

@use "unit.gl" as *;

        // Basic usage
        .element {
        padding: q(16); // 1rem (16 × 0.0625rem)
        margin: q(8); // 0.5rem
        gap: q(24); // 1.5rem
        border-width: q(1); // 0.0625rem (≈1px)
        }

        // Negative values
        .pull-up {
        margin-top: q(-8); // -0.5rem
        }

        // Calculations
        .calculated {
        width: calc(100% - q(32));
        }

8-Point Grid System

unit.gl is designed around an 8-point grid, a widely-adopted standard that provides consistent, harmonious spacing.

// 8-point grid values
        $spacing-xs: q(4); // 4px - Micro spacing
        $spacing-sm: q(8); // 8px - Small spacing
        $spacing-md: q(16); // 16px - Base spacing
        $spacing-lg: q(24); // 24px - Medium spacing
        $spacing-xl: q(32); // 32px - Large spacing
        $spacing-2xl: q(48); // 48px - Extra large
        $spacing-3xl: q(64); // 64px - Section spacing

Why 8?

8 is divisible by 2 and 4, making it easy to create half and quarter values. It also aligns with common icon sizes (16, 24, 32px) and touch targets (48px minimum).

Modular Scale

A modular scale creates harmonious proportions by using a consistent ratio between sizes. unit.gl provides the modular_scale() function for this purpose. 

modular_scale($increment, $base: 1em, $ratio: 1.618)

Common Ratios

Ratio Value Musical Term Use Case
Minor Second 1.067 Semitone Very subtle scale
Major Second 1.125 Whole tone Subtle, conservative
Minor Third 1.200 — Moderate contrast
Major Third 1.250 — Good for body text
Perfect Fourth 1.333 — Balanced contrast
Perfect Fifth 1.500 — Strong contrast
Golden Ratio 1.618 — Classic, dramatic

Typography Example

$ratio: 1.25; // Major Third

        body { font-size: modular_scale(0, 1rem, $ratio); } // 1rem
        h4 { font-size: modular_scale(1, 1rem, $ratio); } // 1.25rem
        h3 { font-size: modular_scale(2, 1rem, $ratio); } // 1.5625rem
        h2 { font-size: modular_scale(3, 1rem, $ratio); } // 1.953rem
        h1 { font-size: modular_scale(4, 1rem, $ratio); } // 2.441rem
        .display { font-size: modular_scale(5, 1rem, $ratio); } // 3.052rem

Layering System

unit.gl provides semantic z-index management to prevent "z-index wars":

canvas z: -1000
content z: 2000
interface z: 4000
modal z: 7000
guides z: 9998 
// Use semantic layer names
        .modal {
        z-index: z("modal"); // 7000
        }

        .navbar {
        z-index: z("interface"); // 4000
        }

        .tooltip {
        z-index: z("interface") + 10; // 4010
        }

Design Philosophy

unit.gl is built on several key principles:

  • Mathematical Harmony Use ratios and scales to create naturally pleasing proportions
  • Consistency Over Convenience Constrained values prevent arbitrary choices
  • Accessibility First REM-based units respect user preferences
  • Composable Architecture Mix functions, mixins, and utilities as needed
