Getting Started

Install unit.gl and start building harmonious, mathematically precise layouts in minutes.

Installation

NPM

Install unit.gl as a development dependency:

npm install unit.gl --save-dev

Yarn

yarn add unit.gl --dev

pnpm

pnpm add unit.gl -D

Basic Setup

Import unit.gl into your main SCSS file:

// Import the entire framework
        @use "unit.gl" as *;

        // Or import specific modules
        @use "unit.gl/scss/variables" as vars;
        @use "unit.gl/scss/functions" as fn;
        @use "unit.gl/scss/mixins" as mx;

Tip

Using @use with namespaces helps avoid naming conflicts in larger projects.

Your First Layout

Here's a minimal example using the q() unit function:

@use "unit.gl" as *;

        // Use q() for consistent spacing
        .card {
        padding: q(16); // 16px (16 × 0.0625rem)
        margin-bottom: q(24); // 24px
        border-radius: q(4); // 4px
        }

        // Typography with modular scale
        h1 {
        font-size: modular_scale(3, 1rem, 1.25); // ~1.95rem
        line-height: q(40);
        }

        // Responsive container
        .container {
        max-width: q(1200);
        padding: q(16);

        @include media_md {
        padding: q(32);
        }
        }

Understanding the Q Unit

The Kyū (Q) is the foundational unit of unit.gl:

Measurement Value Description
1Q 0.0625rem Base unit (1/16th of 1rem)
q(8) 0.5rem / 8px 8 Q units
q(16) 1rem / 16px Standard spacing unit
q(24) 1.5rem / 24px Medium spacing
q(32) 2rem / 32px Large spacing

Why Q?

The Q unit provides pixel-level precision while remaining rem-based for accessibility. It's designed for both digital screens (1Q = 1px at 16px base) and print (1Q = 0.25mm).

Recommended Project Structure

styles/
        ├── main.scss # Main entry point
        ├── _variables.scss # Custom variable overrides
        ├── _base.scss # Base element styles
        ├── _components.scss # Component styles
        └── _utilities.scss # Local utility classes

main.scss

// 1. Import unit.gl
        @use "unit.gl" as *;

        // 2. Override default variables (optional)
        @use "variables";

        // 3. Your styles
        @use "base";
        @use "components";
        @use "utilities";

        import { defineConfig } from 'vite';

        export default defineConfig({
        css: {

        api: 'modern-compiler',

        }
        }
        });

        options: {
        api: 'modern-compiler',

        };

Using Pre-built CSS

If you don't need SCSS customization, use the pre-built CSS directly:

<!-- In HTML -->
        <link rel="stylesheet" href="node_modules/unit.gl/dist/css/unit.gl.css">

        <!-- Or minified -->
        <link rel="stylesheet" href="node_modules/unit.gl/dist/css/unit.gl.min.css">

Or import in your JavaScript:

// In your JS/TS entry file
        import 'unit.gl/css/unit.gl.css';
