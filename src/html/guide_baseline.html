Baseline Grid

Vertical rhythm system using the guide--baseline mixin for consistent typographic alignment.

Default Baseline

The baseline grid uses an 8px unit to maintain consistent vertical rhythm across your design.

Typography on Grid

This block uses the .guide--baseline utility class. The baseline overlay shows the underlying rhythm grid that text should align to.

The quick brown fox jumps over the lazy dog. Line breaks and spacing should align with the rhythm grid to create visual harmony.

Notice how each line of text sits on the baseline, and margins between elements respect the grid unit.

Reading Sample

Good typography is invisible. It should not distract the reader from the content but instead guide them through it with ease and comfort.

The baseline grid provides a framework for this invisibility. When text aligns consistently, the eye can move naturally from line to line without conscious effort.

Josef Müller-Brockmann wrote: "The grid system is an aid, not a guarantee. It permits a number of possible uses and each designer can look for a solution appropriate to his personal style."

Usage

// Apply baseline guide via class <div class="guide--baseline"> Content aligned to baseline grid </div> // Apply via SCSS mixin @use "unit.gl" as *; .my-section { @include guide--baseline; } // Custom baseline height and color .custom-grid { @include guide--baseline( $height: baseline(2), $color: rgba(255, 0, 128, 0.15) ); }

Best Practices

  • Use line-height values that are multiples of the baseline unit
  • Set margin-bottom to maintain rhythm between blocks
  • Avoid arbitrary padding that breaks the vertical flow
  • Test with the grid visible during development
