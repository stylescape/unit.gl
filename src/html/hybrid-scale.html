Mathematical Foundation

LCM (Least Common Multiple)

LCM(4, 5) = 20

The Type Scale (4Q) and Line Scale (5Q) share a least common multiple of 20Q. This ensures both scales align perfectly every 20 pixels, creating natural harmony between typography and vertical rhythm.

Type: 4, 8, 12, 16, 20, 24, 28, 32, 36, 40... Line: 5, 10, 15, 20, 25, 30, 35, 40...

HCN (Highly Composite Numbers)

12, 24, 36, 48, 60, 120, 180, 240, 360, 720...

Highly Composite Numbers have more divisors than any smaller positive integer. The Q format system leverages HCN for maximum flexibility—dimensions like 720, 1080, and 1440 are divisible by many factors, enabling clean subdivisions for grids, columns, and modular layouts.

12 1,2,3,4,6,12 6 divisors
24 1,2,3,4,6,8,12,24 8 divisors
60 1,2,3,4,5,6,10,12,15,20,30,60 12 divisors
120 1,2,3,4,5,6,8,10,12,15,20,24,30,40,60,120 16 divisors
720 Q04 Width: 720px ÷ 5 = 144 lines 30 divisors
1080 Q04 Height: 1080px ÷ 5 = 216 lines 18 divisors

SCSS Functions

type_unit($n)

Returns type-based value: $n × 4Q

font-size: type_unit(4);    // 16Q = 16px
font-size: type_unit(5);    // 20Q = 20px
font-size: type_unit(6);    // 24Q = 24px

line($n)

Returns line-based value: $n × 5Q

line-height: line(4);       // 20Q = 20px
margin-bottom: line(2);     // 10Q = 10px
padding: line(3);           // 15Q = 15px

snap_to_line($value)

Snaps any value to nearest line unit

height: snap_to_line(17px);  // 15px (3 lines)
height: snap_to_line(23px);  // 25px (5 lines)

line_height_for_size($size)

Calculates optimal line-height for font size

// For 16px font
line-height: line_height_for_size(16px);  // 20px

Why Hybrid?

📐

Precision Typography

The 4Q type scale aligns with print standards (1mm = 4px at 96dpi), enabling pixel-perfect font sizing.

📏

Natural Rhythm

The 5Q line scale creates comfortable reading rhythm with line-heights that feel natural.

🔗

LCM Harmony

Every 20Q (20px), both scales align perfectly—creating predictable, harmonious layouts.

🧮

HCN Flexibility

Highly Composite Numbers enable maximum grid subdivisions—720 divides evenly 30 ways.
