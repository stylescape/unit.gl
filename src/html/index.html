Dynamic Layout Engine

unit.gl

A precision-based design system built on the Kyū (Q) unit — enabling consistent, scalable spacing and typography across digital and print.

Get Started View on GitHub

Features

Q

The Q Unit

Atomic unit system based on 0.0625rem (1px). Every measurement derives from this precise foundation.

⊞

8-Point Grid

Enforces spatial harmony with consistent multiples. Elements snap to a uniform rhythm.

φ

Modular Scale

Typography system using mathematical ratios. Golden ratio, Major Third, and more.

⬚

Utility Classes

Tailwind-style classes for rapid prototyping. Spacing, sizing, and responsive variants.

◈

Aspect Ratios

Pre-defined ratios for images, videos, and containers. From square to ultrawide.

≡

Layer System

Semantic z-index management. No more magic numbers for stacking contexts.

Quick Start

// Install via npm
        npm install unit.gl

        // Import in your SCSS
        @use "unit.gl" as *;

        // Use the q() function for precise spacing
        .card {
        padding: q(16); // 1rem (16px)
        margin: q(8); // 0.5rem (8px)
        gap: q(4); // 0.25rem (4px)
        }

        // Or use utility classes directly
        <div class="p_q16 m_q8 gap_q4">...</div>

The Q Unit

The foundation of unit.gl is the Kyū (Q) — a base unit equal to 0.0625rem (1px at 16px root). All spacing, sizing, and typography derive from this atomic measurement.
