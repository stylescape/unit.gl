Overview

Managing z-index values across a large project quickly becomes chaotic. The common approach of using arbitrary numbers like z-index: 9999 leads to an arms race where values keep increasing without any logic or system.

unit.gl solves this with a semantic layering system. Instead of numbers, you use meaningful names that describe the purpose of each layer. The z() function maps these names to carefully structured z-index values.

@use "unit.gl" as *; // Instead of this... .modal { z-index: 9999; } .header { z-index: 999; } .dropdown { z-index: 100; } // Use semantic names .modal { z-index: z("modal"); } // 7000 .header { z-index: z("interface"); } // 4000 .dropdown { z-index: z("content"); } // 2000

The Layer Stack

The default layer stack provides five semantic layers with well-spaced z-index values. The large gaps (1000–3000 units) between layers allow room for relative positioning without conflicts.

The z() Function

z($layer)

Returns the z-index value for the specified layer name.

Parameters

$layer String The name of the layer (e.g., "modal", "interface", "content")

Returns

Number — The z-index value associated with the layer, or null if not found.

Example

@use "unit.gl" as *; .modal-overlay { position: fixed; inset: 0; z-index: z("modal"); // 7000 } .sticky-header { position: sticky; top: 0; z-index: z("interface"); // 4000 } .card { position: relative; z-index: z("content"); // 2000 } .background-pattern { position: absolute; z-index: z("canvas"); // -1000 }

Relative Positioning

Sometimes you need elements to stack relative to a layer rather than exactly on it. Use simple arithmetic with the z() function:

// Dropdown trigger and menu .dropdown-trigger { z-index: z("content"); // 2000 } .dropdown-menu { z-index: z("content") + 10; // 2010 } // Modal with backdrop .modal-backdrop { z-index: z("modal") - 1; // 6999 } .modal-dialog { z-index: z("modal"); // 7000 } // Nested cards .card { z-index: z("content"); } .card__overlay { z-index: z("content") + 1; } .card__actions { z-index: z("content") + 2; }

Tip

Use small offsets (+1, +5, +10) for related elements. The large gaps between layers (1000–3000 units) give you plenty of room.

Customization

You can extend or override the default layer map to fit your project's needs:

// Override $layer_map before importing unit.gl $layer_map: ( "canvas": -1000, "background": 0, "content": 2000, "dropdown": 3000, // Custom layer "sticky": 3500, // Custom layer "interface": 4000, "overlay": 5000, // Custom layer "modal": 7000, "toast": 8000, // Custom layer "tooltip": 8500, // Custom layer "guides": 9998, ); @use "unit.gl" as * with ($layer_map: $layer_map); // Now use your custom layers .toast-notification { z-index: z("toast"); // 8000 } .tooltip { z-index: z("tooltip"); // 8500 }

Best Practices

✓ Use semantic names

Always use the z() function with meaningful layer names. Never hardcode z-index values.

✓ Respect the hierarchy

Follow the layer order: canvas → content → interface → modal → guides. Don't skip layers without reason.

✓ Use offsets sparingly

When you need relative stacking, use small offsets (+1 to +10). If you need larger gaps, consider adding a custom layer.

✓ Document custom layers

If you add custom layers to $layer_map, document their purpose and position in the stack.

✗ Avoid z-index: 9999

The "make it bigger" approach leads to unmaintainable code. Use the layer system instead.

✗ Don't create stacking context chaos

Remember that position: relative/absolute/fixed with z-index creates new stacking contexts. Plan accordingly.

Understanding Stacking Contexts

Z-index only works within a stacking context. Several CSS properties create new stacking contexts:

  • position (relative, absolute, fixed, sticky) with z-index other than auto
  • opacity less than 1
  • transform, filter, perspective
  • isolation: isolate
  • Flex/Grid items with z-index other than auto

A child element cannot escape its parent's stacking context. If a modal is inside a container with z-index: 1, setting the modal to z-index: 9999 won't place it above a sibling with z-index: 2.

// Problem: Modal trapped in stacking context .sidebar { position: relative; z-index: 1; // Creates stacking context } .sidebar .modal { z-index: z("modal"); // 7000, but still below main content! } // Solution: Move modal outside or use isolation .sidebar { position: relative; // No z-index, no stacking context } .main-content { isolation: isolate; // Contains its own stacking }

Key Insight

The layer system provides consistent z-index values, but you still need to manage stacking contexts. Place modals and overlays at the root level of your DOM when possible.
