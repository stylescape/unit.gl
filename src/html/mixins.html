API Reference

Mixins

Reusable SCSS mixins for responsive design, ratios, guides, and common patterns.

Responsive Breakpoints

Mobile-first breakpoint mixins built on the $breakpoints map.

breakpoint()

Apply styles at a named breakpoint and above.

@include breakpoint($size) { ... }
$size String Breakpoint key from $breakpoints

Available Breakpoints

Name Min Width Q Format Typical Devices
us240pxQ07 Portrait (60mm)Compact/fold devices
ss360pxQ06 Portrait (90mm)Phones
xs540pxQ05 Portrait (135mm)Large phones
sm720pxQ04 Portrait (180mm)Tablets
md1440pxQ03 Landscape (360mm)Laptops
lg2160pxQ02 Landscape (540mm)QHD desktops
xl2880pxQ01 Landscape (720mm)4K displays
ul4320pxQ00 Landscape (1080mm)5K+ displays

Examples

.container {
    padding: q(16);

    @include breakpoint(md) {
        padding: q(24);
    }

    @include breakpoint(lg) {
        padding: q(32);
        max-width: 1200px;
        margin: 0 auto;
    }
}

.grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: q(16);

    @include breakpoint(sm) {
        grid-template-columns: repeat(2, 1fr);
    }

    @include breakpoint(lg) {
        grid-template-columns: repeat(4, 1fr);
        gap: q(24);
    }
}

media_us, media_ss, media_xs, media_sm, media_md, media_lg, media_xl, media_ul

Per-breakpoint shortcut mixins. Equivalent to @include breakpoint($name) but more concise.

.sidebar {
    display: none;

    @include media_md {
        display: block;
    }
}

Aspect Ratio Mixins

Apply aspect ratios to containers using the modern aspect-ratio property.

aspect_ratio()

Sets a custom aspect ratio on an element.

@include aspect_ratio($width, $height)
$width Number Width portion of the ratio
$height Number Height portion of the ratio 
.video-container {
    @include aspect_ratio(16, 9);
}

.square {
    @include aspect_ratio(1, 1);
}

.photo {
    @include aspect_ratio(4, 3);
}

aspect_ratio--{ratio}

Predefined aspect-ratio mixins for common ratios. Each is a standalone mixin (no arguments).

}

Guide Mixins

Visual overlay mixins for development and layout debugging.

guide--baseline

Renders a baseline grid overlay for vertical-rhythm debugging.

@include guide--baseline
// Apply to a layer element
.guide-overlay {
    @include guide--layer;
    @include guide--baseline;
}

guide--graph / guide--graph_centered

Renders a graph (column) grid overlay. The _centered variant aligns the grid to the viewport center.

@include guide--graph
@include guide--graph_centered
.guide-overlay {
    @include guide--layer;
    @include guide--graph_centered;
}

guide--margin

Highlights margin areas for layout inspection.

@include guide--margin
.guide-overlay {
    @include guide--layer;
    @include guide--margin;
}

guide--layer

Base layer mixin -- positions the overlay element fixed across the viewport. Combine with one of the visual guides above.

@include guide--layer

guide--centered

Centers a guide horizontally within its container.

@include guide--centered

Layout Mixins

Helpers for sizing, positioning, and viewport-relative containers.

container

Wraps content in a width-constrained container.

@include container
.page {
    @include container;
}

center_x / center_y

Absolute-positioning helpers that center an element horizontally or vertically within its positioned ancestor.

@include center_x
@include center_y
.modal {
    position: absolute;
    @include center_x;
    @include center_y;
}

set_size / set_width / set_height

Apply sizing using Q units.

@include set_size($q-value)
@include set_width($q-value)
@include set_height($q-value)
.thumb {
    @include set_size(64);   // 64 × q(1)
}

.divider {
    @include set_width(240);
    @include set_height(1);
}

Device & Format Mixins

format()

Applies dimensions from a page/print format defined in $paper_map.

@include format($size, $orientation: portrait)

Available Formats

Size Dimensions (portrait)
a3297mm × 420mm
a4210mm × 297mm
a5148mm × 210mm
letter216mm × 279mm
legal216mm × 356mm
 
.print-preview {
    @include format(a4, portrait);
}

.landscape-doc {
    @include format(letter, landscape);
}

device_media_query()

Generates a media query that matches a profile from the $devices map.

@include device_media_query($name) { ... }
.panel {
    padding: q(8);

    @include device_media_query("iphone_x") {
        padding: q(16);
    }

    @include device_media_query("macbook_pro") {
        padding: q(32);
    }
}

Utility Generation

Mixins that emit utility classes from the $q_steps ladder. These are invoked by src/scss/utilities.scss and you only need to call them yourself when generating custom builds.

Spacing utilities

Each mixin emits a family of .{prefix}_q{step} classes for every value in $q_steps.

@include padding_utilities
@include padding_logical_utilities
@include margin_utilities
@include margin_logical_utilities
@include gap_utilities
// Generates .p_q*, .pt_q*, .pb_q*, .pl_q*, .pr_q*
@include padding_utilities;

// Generates .m_q*, .mt_q*, .mb_q*, .ml_q*, .mr_q*
@include margin_utilities;

// Generates .gap_q*
@include gap_utilities;

Sizing utilities

@include size_utilities
@include width_utilities
@include height_utilities
// Generates .w_q*, .h_q*, and .size_q*
@include size_utilities;

Border utilities

@include border_width_utilities
@include border_radius_utilities
@include outline_width_utilities
@include outline_offset_utilities
@include border_width_utilities;
@include border_radius_utilities;

Position utilities

@include inset_utilities
@include inset_logical_utilities
@include translate_utilities
@include inset_utilities;
@include translate_utilities;
