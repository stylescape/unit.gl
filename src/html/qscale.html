What is q()?

q() is an atomic unit: q(1) = 0.0625rem (1px at a 16px root). The utilities use a curated step map ($q_steps) to stay granular without exploding CSS size.

When to Use Q Units

✓ Use q() for

  • Spacing and padding
  • Component dimensions
  • Grid gaps
  • Border widths
  • Icon sizes

✗ Avoid q() for

  • Font sizes (use type scale)
  • Line heights (use line scale)
  • Percentage-based layouts
  • Viewport-relative units
