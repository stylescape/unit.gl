Ratio Reference

Ratio Class Decimal Common Use
1:1 .ratio_1x1 1.000 Social media, thumbnails
4:3 .ratio_4x3 1.333 Classic TV, presentations
3:2 .ratio_3x2 1.500 35mm photography
16:9 .ratio_16x9 1.778 HD video, monitors
21:9 .ratio_21x9 2.333 Cinematic, ultrawide
2:3 .ratio_2x3 0.667 Portrait photos
9:16 .ratio_9x16 0.563 Stories, vertical video

Usage

<!-- Apply ratio class to container -->
        <div class="ratio_16x9">
        <img src="video-thumb.jpg" alt="Video">
        </div>

        <!-- With responsive images -->
        <div class="ratio_4x3">
        <picture>
        <source srcset="large.webp" media="(min-width: 1024px)">
        <img src="small.jpg" alt="Photo">
        </picture>
        </div>

        <!-- Video embed -->
        <div class="ratio_16x9">
        <iframe src="https://youtube.com/embed/..."></iframe>
        </div>

SCSS Usage

// Using ratio variables
        @use "unit.gl" as *;

        .hero-image {
        aspect-ratio: $ratio-16x9;
        }

        .profile-avatar {
        aspect-ratio: $ratio-1x1;
        border-radius: 50%;
        }

        // Custom ratio with math
        .golden-container {
        aspect-ratio: 1 / 1.618; // Golden ratio
        }
